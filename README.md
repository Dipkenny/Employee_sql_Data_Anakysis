# Employee Data Analysis Using SQL

## Project Overview
This project analyzes employee data using SQL. The database consists of employee records, departments, salaries, job titles, department assignments, and managerial information.

## Dataset Tables
* employees
* departments
* dept_employee
* dept_manager
* salaries
* titles

## Analysis Performed
* Employee Information Retrieval
* Department Analysis
* Salary Analysis
* Manager Identification
* Hiring Trend Analysis
* Department Workforce Analysis

## SQL Skills Used
* Joins
* Aggregate Functions
* Group By
* Order By
* Date Functions
* Filtering
* Relational Database Design

## Key Insights
* Identified departments with the largest workforce.
* Analyzed employee salaries.
* Retrieved managerial assignments.
* Examined employee hiring patterns.
* Investigated departmental structures.
